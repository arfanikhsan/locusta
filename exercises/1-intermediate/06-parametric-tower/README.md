# 06 – Parametric Tower

**Level:** Intermediate · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Design a twisting, tapering tower with floor slabs, facade mullions and a core, all controlled by a few sliders.

## Learning goals
- Series and transforms per floor
- Lofting from section curves
- Graph Mapper for profile control

## Key components
- `Series`
- `Polygon`
- `Rotate`
- `Scale`
- `Move`
- `Loft`
- `Contour`
- `Graph Mapper`

## Steps
1. [ ] Create a base floor outline
2. [ ] Copy it up with Series for floor heights
3. [ ] Rotate and scale per floor using Graph Mappers
4. [ ] Loft the envelope and extract slabs
5. [ ] Add mullions by dividing slab edges

## Stretch goals
- [ ] Calculate GFA and floor count outputs
- [ ] Colour floors by area
