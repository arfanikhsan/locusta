# 02 – Data Tree Management

**Level:** Intermediate · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Master data trees: build a grid of points on a surface and connect them in structured ways (rows, columns, diagonals).

## Learning goals
- Reading tree paths with Param Viewer
- Graft, Flatten, Simplify, Flip Matrix
- Shift List / Cull Pattern to pair items
- Path Mapper and Relative Item

## Key components
- `Divide Surface`
- `Param Viewer`
- `Flip Matrix`
- `Shift List`
- `Path Mapper`
- `Relative Item`
- `Tree Branch`

## Steps
1. [ ] Divide a surface into a UV point tree
2. [ ] Draw polylines along rows, then columns (Flip Matrix)
3. [ ] Create diagonals with Shift List
4. [ ] Build quad/triangle panels from four corner points
5. [ ] Document each tree structure with Param Viewer screenshots

## Stretch goals
- [ ] Diamond panelling without plugins
- [ ] Checkerboard selection using Dispatch on tree paths
