# 04 – Voronoi Patterns

**Level:** Intermediate · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Generate 2D and 3D Voronoi patterns, then refine them into smooth, filleted screens.

## Learning goals
- Populate / random seeds
- Voronoi cells and offsets
- Density control with attractors

## Key components
- `Populate 2D`
- `Voronoi`
- `Offset Curve`
- `Fillet`
- `Boundary Surfaces`
- `Extrude`

## Steps
1. [ ] Populate a rectangle with random points
2. [ ] Generate Voronoi cells
3. [ ] Scale/offset cells inward
4. [ ] Fillet corners and create a perforated panel
5. [ ] Control density with an attractor (Populate with weights or cull)
