# 07 – Mesh Fundamentals

**Level:** Intermediate · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Work with meshes directly: construct, deconstruct, colour, and smooth them.

## Learning goals
- Mesh vertices, faces, normals
- Mesh colouring by analysis
- Subdivision and thickening

## Key components
- `Construct Mesh`
- `Deconstruct Mesh`
- `Mesh Colours`
- `Face Normals`
- `Weaverbird Subdivide`
- `Mesh Thicken`

## Steps
1. [ ] Build a mesh from a point grid with Construct Mesh
2. [ ] Colour faces by height or slope
3. [ ] Subdivide with Catmull-Clark
4. [ ] Create a frame / window per face
5. [ ] Thicken into a printable object

## Stretch goals
- [ ] Mesh curvature analysis
- [ ] Convert to SubD and back
