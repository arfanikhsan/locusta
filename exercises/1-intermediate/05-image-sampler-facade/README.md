# 05 – Image Sampler Facade

**Level:** Intermediate · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Translate an image into a facade pattern where brightness drives opening size or fin rotation.

## Learning goals
- Image Sampler setup
- Mapping colour channels to geometry
- Facade grids on a building envelope

## Key components
- `Image Sampler`
- `Square Grid`
- `Split ARGB / Brightness`
- `Remap Numbers`
- `Rotate / Scale`

## Steps
1. [ ] Create a facade grid
2. [ ] Sample an image at each cell
3. [ ] Map brightness to opening radius
4. [ ] Swap circles for rotating fins
5. [ ] Map the pattern onto a curved facade surface
