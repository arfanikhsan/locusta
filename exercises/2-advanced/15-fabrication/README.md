# 15 – Digital Fabrication

**Level:** Advanced · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Prepare a design for fabrication: waffle structures, unrolling, nesting and labelling.

## Learning goals
- Sectioning / waffle notches
- Unrolling developable strips
- Nesting on sheets
- Labelling and export

## Key components
- `Contour`
- `Brep | Plane`
- `Unroll (Python / OpenNest)`
- `Text Tag 3D`
- `Orient`

## Steps
1. [ ] Create a waffle structure from a freeform object
2. [ ] Generate notches at intersections
3. [ ] Lay parts flat with labels
4. [ ] Nest onto standard sheet sizes
5. [ ] Export cut files

## Stretch goals
- [ ] Unroll a paneled surface with tabs
- [ ] Estimate material usage and cost
