## Brief
Simulate agents (boids, slime mould, stigmergy) and turn their trails into geometry.

## Learning goals
- Agent state and update rules
- Separation, alignment, cohesion
- Trail-to-geometry conversion

## Key components
- `Python / C# script`
- `Anemone (alt)`
- `Interpolate`
- `Pipe / Multipipe`

## Steps
1. [ ] Implement a 2D flocking simulation in a script component
2. [ ] Record agent trails
3. [ ] Constrain agents to a surface
4. [ ] Convert trails into a structure (Multipipe / mesh)
