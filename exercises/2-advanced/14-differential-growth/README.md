# 14 – Differential Growth

**Level:** Advanced · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Grow a curve that buckles and folds, using collision and edge-length goals.

## Learning goals
- Curve subdivision during simulation
- Collision avoidance
- Constraining growth to a boundary

## Key components
- `Kangaroo2 Solver`
- `SphereCollide`
- `Length`
- `CurvePull`
- `Anemone / Python loop`

## Steps
1. [ ] Start with a small circle
2. [ ] Subdivide edges that exceed a length
3. [ ] Keep points apart with SphereCollide
4. [ ] Constrain growth inside a boundary curve
5. [ ] Extrude / pipe the result
