# 09 – Form Finding with Kangaroo

**Level:** Advanced · **Status:** ⬜ Not started

![result](images/result.png)

## Brief
Use physics simulation to form-find tensile structures, gridshells and inflated forms.

## Learning goals
- Goals: Anchor, Length, Load, Pressure
- Mesh relaxation
- Solver settings and convergence

## Key components
- `Kangaroo2 Solver`
- `Anchor`
- `Length (Line)`
- `Load`
- `Show`
- `EdgeLengths`
- `Pressure`

## Steps
1. [ ] Hanging catenary chain from a line
2. [ ] Hanging mesh (catenary vault) and flip it
3. [ ] Tensile membrane between masts
4. [ ] Inflated pillow with Pressure goal

## Stretch goals
- [ ] Planar quad panels with Planarize goal
- [ ] Gridshell from bending-active rods
